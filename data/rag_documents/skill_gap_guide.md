# Competency Skill Gap Analysis & Development Mechanics

## Gap Calculation Model
Competency skill gap analysis is strictly deterministic:
Skill Gap = Required Competency Level - Current User Competency Level

## Gap Categorization & Priority Matrix
- Gap <= 0: Meets Target (User meets or exceeds the required proficiency level).
- Gap == 1: Small Gap (Low Priority) (Can be bridged with self-paced micro-learning and targeted scenario exercises).
- Gap == 2: Moderate Gap (Medium Priority) (Requires formal coursework, practical application, and mock assessments).
- Gap >= 3: High-Priority Gap (Requires an intensive multi-step development journey: core course + simulation + peer review + supervised assessment).

## Recommended Learning Progression Chain
Every identified competency gap triggers a 5-stage closed-loop learning cycle:
1. Skill Gap Identified: Priority and exact level delta determined.
2. Course Recommendation: Direct enrollment in curated iGOT / NCGG / ISTM modules.
3. Practical Application: Real-world drafting, case analysis, or SLA monitoring exercise.
4. Assessment & Practice: AI Mock Tests with scenario-based MCQs and instant diagnostic feedback.
5. Re-evaluation & Progress Passport Update: Baseline score updated upon passing benchmark.
